# Project status

- Next.js App Router + TypeScript scaffold.
- Dark sports design system and responsive layouts.
- Public homepage, sports directory/detail, fixtures, teams, athletes, news.
- Initial dashboard shell.
- PWA manifest and install banner foundation.
- Domain contracts and architecture notes.
- PostgreSQL bootstrap migration.
- Repeatable initial sports/team/competition/fixture seed scripts.

- Transfer approvals.
- Media upload pipeline.
- TikTok LIVE embed resolver.
- Push notification service worker.

Do not present this scaffold as production-ready until the security and backend milestones are implemented and tested.
