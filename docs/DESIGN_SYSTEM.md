# Design system

## Brand direction

Caritas Sports should feel like a premium sports product: confident, editorial, energetic and useful. The public home borrows the dramatic sports photography and typography of the first reference. The application screens follow the dark olive/charcoal and electric-lime direction of the second reference.

## Tokens

| Token | Value | Use |
|---|---|---|
| Background | `#11130F` | App canvas |
| Surface | `#1D2019` | Cards and navigation |
| Raised | `#292D24` | Nested cards and inputs |
| Accent | `#B8FF16` | Primary actions and live state |
| Text | `#F5F6F0` | Main text |
| Muted | `#92978B` | Secondary text |
| Border | `rgba(255,255,255,.08)` | Separation |

## Rules

- No gradients.
- No emoji icons.
- Use Lucide icons.
- Use accent sparingly; reserve it for actions, selection and live states.
- Use actual association/player photography once approved assets are available.
- Keep match scores and status highly scannable.
- On mobile, use bottom navigation and compact cards.
- On desktop, use a restrained sidebar and wider editorial content.
- Provide visible focus states and sufficient contrast.
